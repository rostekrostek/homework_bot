# Бот для сдачи домашних заданий (испанский язык)

Состоит из двух независимых процессов:

- **`bot.py`** — телеграм-бот. Студенты пишут ему `/start`, регистрируются
  (имя + группа, выбирается кнопками из списка), затем присылают текст,
  голосовые сообщения или файлы (Word, PDF, PowerPoint, Excel и т.д., можно
  сразу несколько файлов одним альбомом) с заданиями. Кнопка «📜 Моя
  история» показывает список сданных работ и отзывов прямо в боте. При
  каждой новой работе бот присылает уведомление в Telegram всем
  преподавателям со ссылкой на веб-панель, а при получении отзыва (в том
  числе повторного/отредактированного) — уведомляет студента.
- **`web.py`** — веб-панель (открывается в браузере по IP вашего VDS).
  Список сданных работ с поиском по имени/тексту/подписи, прослушивание
  голосовых, скачивание файлов (в том числе нескольких за раз), написание
  текстового и/или голосового отзыва (можно записать прямо в браузере или
  загрузить аудиофайл), список всех студентов с сортировкой/фильтрацией по
  группам, управление списком групп, редактирование карточки студента и
  личные заметки преподавателя. Есть переключатель светлой/тёмной темы.

Оба процесса используют общую базу данных SQLite (`homework.db`), которая
создастся автоматически при первом запуске. При обновлении поверх старой
установки новые колонки и таблицы (`notes`, `original_filename`, `groups`,
`submission_files`, `feedback_voice_path` и т.д.) добавятся в базу
автоматически при старте — ничего вручную мигрировать не нужно, старые
записи и старые значения групп (текстом) сохраняются как есть.

### Новое в этой версии

1. **Группы через кнопки.** На вкладке «Группы» в панели вы заводите список
   групп. При регистрации в боте студент выбирает группу нажатием кнопки, а
   не вводом текста. Если групп ещё нет — бот попросит ввести группу текстом
   (как раньше), чтобы никто не застрял без возможности зарегистрироваться.
2. **История в боте.** Кнопка «📜 Моя история» (или команда `/history`)
   показывает список работ с пагинацией; по нажатию на работу студент видит
   статус и текст отзыва, а если был голосовой отзыв — бот тут же пришлёт
   его файлом.
3. **Несколько файлов за раз.** Если студент выделяет и отправляет сразу
   несколько файлов (альбомом), бот подождёт секунду-полторы, соберёт все
   файлы в одно задание и покажет их в панели списком.
4. **Уведомление об изменении отзыва.** Если вы отредактировали уже
   отправленный отзыв, студент получит сообщение с пометкой «✏️ Отзыв
   обновлён» вместо обычного «📝 Отзыв», чтобы не запутаться.
5. **Поиск по работам** — строка поиска над списком заданий ищет по имени
   студента, тексту ответа и подписи к заданию, независимо от статуса.
6. **Голосовые отзывы преподавателя.** В карточке задания можно записать
   голосовой отзыв прямо в браузере (кнопка «🎙️ Записать») или загрузить
   готовый аудиофайл («📁 Загрузить аудиофайл») — он уйдёт студенту в
   Telegram как голосовое сообщение.

   ⚠️ Запись через микрофон в браузере требует **HTTPS или доступа с
   localhost** — это ограничение самих браузеров, не панели. Пока у панели
   нет HTTPS (см. раздел «О безопасности» ниже), записывайте голосовые
   заметки на телефоне/компьютере и загружайте их кнопкой «Загрузить
   аудиофайл» — она работает всегда.

   Для отправки голосового отзыва именно как «голосового сообщения» (с
   волной и значком play, а не обычным аудиофайлом) на сервере должен быть
   установлен **ffmpeg** — панель сама конвертирует запись в нужный формат
   (.ogg/OPUS). Если ffmpeg не установлен, отзыв всё равно дойдёт до
   студента, но как обычный аудиофайл. Установить:
   ```bash
   sudo apt install -y ffmpeg
   ```

## 1. Что нужно подготовить

### 1.1. Создать бота и получить токен

1. Откройте в Telegram **@BotFather**.
2. Отправьте `/newbot`, следуйте инструкциям, придумайте имя и username бота.
3. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` —
   он понадобится дальше как `BOT_TOKEN`.

### 1.2. Узнать свой Telegram chat_id (можно несколько преподавателей)

Это нужно, чтобы бот знал, кому слать уведомления о новых работах.

1. Откройте в Telegram **@userinfobot** (или @getmyid_bot).
2. Отправьте ему любое сообщение — он пришлёт в ответ ваш числовой ID.
3. Повторите для каждого преподавателя, которому нужны уведомления и доступ
   к панели.

Если преподавателей несколько, укажите все ID через запятую в переменной
`TEACHER_CHAT_IDS` (см. ниже) — уведомление о новой работе придёт каждому.

**Важно:** после установки бота каждый преподаватель должен написать ему
`/start` вручную хотя бы раз (с того же Telegram-аккаунта, чей chat_id вы
указали) — Telegram не позволяет боту первым написать пользователю, если тот
никогда не начинал с ним диалог.

## 2. Установка на VDS (Ubuntu/Debian)

Подключитесь к серверу по SSH и выполните:

```bash
# Системные зависимости
sudo apt update
sudo apt install -y python3 python3-venv python3-pip git

# Скопируйте папку проекта на сервер (например, через scp/git),
# либо распакуйте архив, который вам прислали. Дальше предполагается,
# что проект лежит в /home/YOUR_LINUX_USER/homework-bot

cd /home/YOUR_LINUX_USER/homework-bot

# Виртуальное окружение
python3 -m venv venv
source venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt

# ffmpeg нужен для голосовых отзывов преподавателя (см. ниже) — необязательно,
# но без него голосовые отзывы уйдут студенту обычным аудиофайлом, а не
# "голосовым сообщением"
sudo apt install -y ffmpeg
```

### 2.1. Настройте `.env`

```bash
cp .env.example .env
nano .env
```

Заполните:

```
BOT_TOKEN=токен_от_botfather
TEACHER_CHAT_IDS=ваш_chat_id,chat_id_второго_преподавателя
PANEL_PASSWORD=надёжный_пароль_для_панели
SECRET_KEY=случайная_строка
WEB_HOST=0.0.0.0
WEB_PORT=8080
PANEL_BASE_URL=http://ВАШ_IP_VDS:8080
```

Если преподаватель один — просто укажите один ID в `TEACHER_CHAT_IDS`
(старая переменная `TEACHER_CHAT_ID` тоже по-прежнему поддерживается для
совместимости, но новую панель проще настраивать через `TEACHER_CHAT_IDS`).

Сгенерировать `SECRET_KEY` можно так:

```bash
python3 -c "import secrets; print(secrets.token_hex(32))"
```

### 2.2. Откройте порт панели в файрволе

Если используете `ufw`:

```bash
sudo ufw allow 8080/tcp
```

Если провайдер VDS даёт отдельную панель управления фаерволом (Timeweb,
Selectel и т.п.) — там тоже нужно открыть входящий TCP на порт 8080
(или тот, что вы указали в `WEB_PORT`).

### 2.3. Проверка вручную (до автозапуска)

```bash
source venv/bin/activate
python bot.py     # в одном терминале/сессии tmux
python web.py     # в другом
```

Напишите боту `/start` в Telegram и откройте `http://ВАШ_IP:8080` в браузере.
Если всё работает — переходите к автозапуску через systemd, чтобы бот и
панель поднимались сами при перезагрузке сервера и перезапускались при сбое.

## 3. Автозапуск через systemd

```bash
# Отредактируйте юниты — замените YOUR_LINUX_USER на ваше реальное имя пользователя
nano systemd/homework-bot.service
nano systemd/homework-panel.service

# Скопируйте их в системную папку
sudo cp systemd/homework-bot.service /etc/systemd/system/
sudo cp systemd/homework-panel.service /etc/systemd/system/

# Перечитайте конфигурацию systemd и включите автозапуск
sudo systemctl daemon-reload
sudo systemctl enable --now homework-bot.service
sudo systemctl enable --now homework-panel.service
```

Проверить статус и логи:

```bash
sudo systemctl status homework-bot.service
sudo systemctl status homework-panel.service

journalctl -u homework-bot.service -f     # логи бота в реальном времени
journalctl -u homework-panel.service -f   # логи панели
```

После правок в `.env` или коде — перезапустите:

```bash
sudo systemctl restart homework-bot.service
sudo systemctl restart homework-panel.service
```

## 4. Как это выглядит для студента

1. Находит бота в Telegram, жмёт **Start**.
2. Бот спрашивает имя, затем показывает список групп кнопками — студент
   нажимает свою (если групп в панели ещё нет, бот попросит ввести группу
   текстом, как раньше).
3. Дальше просто присылает боту текст задания, голосовое сообщение или один
   либо сразу несколько файлов (Word, PDF, PowerPoint, Excel — список
   расширений в `config.py`, `ALLOWED_DOCUMENT_EXTENSIONS`), коротко
   подписывая, что это за задание.
4. Когда вы оставите отзыв в панели — студент получит его в Telegram (текстом
   и/или голосовым сообщением). Если вы позже отредактируете отзыв, студент
   получит уведомление с пометкой, что отзыв обновлён.
5. Кнопка **«📜 Моя история»** под полем ввода показывает список всех сданных
   работ с пагинацией — нажав на работу, студент видит её статус и отзыв.

Файлы крупнее 20 МБ бот не примет — это ограничение самого Telegram Bot API.

## 5. Как это выглядит для вас

1. Приходит уведомление в Telegram всем преподавателям из `TEACHER_CHAT_IDS`:
   кто сдал, что за задание (в том числе сколько файлов, если их несколько),
   ссылка на панель.
2. Переходите по ссылке → `http://ВАШ_IP:8080` → вводите пароль из `.env`.
3. На главной странице — список новых работ, а сверху строка поиска по
   имени студента, тексту ответа и подписи. Открываете нужную работу,
   слушаете голосовое, скачиваете файл(ы) или читаете текст.
4. Пишете отзыв: текстом, голосом (запись в браузере или загрузка готового
   аудиофайла) или и то, и другое сразу — жмёте «Отправить студенту». Отзыв
   уходит в Telegram, работа помечается как проверенная; если правите отзыв
   повторно — студент получит пометку, что отзыв обновлён.
5. Во вкладке **«Группы»** заводите и переименовываете список групп —
   именно из этого списка студенты будут выбирать группу кнопками в боте.
   Удаление группы не удаляет студентов — они просто останутся без
   привязки к формальной группе (их прежнее название группы сохранится как
   текст).
6. Во вкладке **«Студенты»** — список всех студентов с количеством сданных
   работ. Можно отфильтровать по группе (выпадающий список вверху) и
   отсортировать по имени, группе или последней активности. Открыв карточку
   студента, можно исправить имя/фамилию, привязать к группе из списка и
   оставить личную заметку — она видна только преподавателям в панели и
   никогда не отправляется студенту.
7. Кнопка ☀️/🌙 в шапке переключает светлую и тёмную тему; выбор
   запоминается в браузере.

## 6. О безопасности (важно прочитать)

Сейчас панель открывается по обычному `http://` (без SSL), потому что у VDS
пока нет домена. Это значит, что пароль от панели и содержимое заданий
технически можно перехватить при определённых условиях (например, в
незащищённой Wi-Fi сети). Для учебного бота с некритичной информацией это
обычно приемлемый риск на старте, но два простых улучшения на будущее:

- Если появится домен — можно бесплатно настроить HTTPS через Let's Encrypt
  (например, через `certbot` + `nginx` как обратный прокси перед портом 8080).
  Просто скажите — помогу настроить, когда будет домен.
- Ограничить доступ к порту 8080 только с вашего IP через `ufw`, если вы
  заходите в панель всегда с одного и того же места:
  ```bash
  sudo ufw allow from ВАШ_IP to any port 8080
  ```

Все преподаватели из `TEACHER_CHAT_IDS` заходят в панель под одним и тем же
паролем (`PANEL_PASSWORD`) — отдельных учётных записей пока нет.

## 7. Возможные доработки на будущее

- Голосовые отзывы от преподавателя (не только текст).
- Отдельные логины для каждого преподавателя вместо общего пароля.
- Экспорт истории заданий студента в файл.
- Напоминания студентам, если задание не сдано к сроку.

Если что-то из этого понадобится — просто скажите, дополним.
